# 撞牌 Version 3 · 双主题改良版（课程设计）

根据《撞牌游戏 Version 3——双主题改良版完整规则》制作的网页牌桌。三人一桌，可以真人和电脑混合。
同一张牌桌，每局在三人下完底注后随机抽目标：**13「撞庄局」** 或 **22「命中局」**，各占一半。

## 在线游玩

打开 **[撞牌 V3 在线游戏](https://jimmy-hu-323.github.io/zhuangpai-v3/)** 即可开始，无需下载或登录。

当前版本支持与电脑对局，也支持多名真人共用一台设备轮流操作。不同设备打开链接会各自运行独立牌局，不包含跨设备联机房间。

## 本地启动

| 电脑 | 操作 |
| --- | --- |
| Mac | 双击 `启动游戏_Mac.command` |
| Windows | 双击 `启动游戏_Windows.bat` |
| 任何电脑 | 直接双击 `index.html` 也可以 |

不需要联网，不需要安装任何软件，用 Chrome、Edge、Safari、Firefox 的近期版本都能运行。

**Mac 第一次双击提示“无法打开”**：在 `启动游戏_Mac.command` 上点右键 →“打开”→ 再点“打开”。
如果提示“没有权限”（通过微信或压缩包传过来时常见），打开“终端”，输入 `chmod +x ` 后把这个文件拖进终端窗口，回车即可。实在不行就直接双击 `index.html`。

## 两种目标

| | 目标 13「撞庄局」 | 目标 22「命中局」 |
| --- | --- | --- |
| 玩家起手 | 1 张公开，最多 3 张 | 2 张公开，最多 4 张 |
| 庄家 | 1 张暗牌起手，不足 10 必补，最多 3 张 | 1 张暗牌起手，不足 19 必补，最多 3 张 |
| 边注 | 开局注：从底注划出 10%，庄家首牌 10／10 净赢 9 倍，整桌结束、主注全退 | 终局注：另付底注 10%，两庄终局同距净赢 8.1 倍 |
| 主游戏 | 普通获胜 1 赔 1；两庄相撞获胜 2 赔 1（含加注） | 普通获胜 1 赔 1；正好 22 并获胜，原底注 2 赔 1、加注 1 赔 1 |

## 一局的流程（左侧会显示进行到哪一步）

1. 三人下底注（100 至 5,000，以 100 为单位）。行动顺序每局轮换。
2. 随机抽目标，发起手牌（全部公开）；庄家各一张暗牌。
3. 选择要不要买本目标的边注。
4. 翻开庄家首牌。目标 13 如果是 10 点／10 点，整桌立即结束。
5. 三人各自选“继续／加注／弃牌”，全部选好后同时亮出。加注最多三倍底注，加注后必须再拿一张然后停牌；弃牌退回主注的 60%。
6. 按顺序要牌或停牌，补来的牌只有自己能看。多名真人共用一台电脑时，会先出现遮挡页。
7. 庄家按固定门槛补牌。
8. 先撞后比：同距离的一起出局，剩下的离目标近者胜；三手全撞，主注退回。

快捷键：`H` 要牌，`S` 停牌；边注 `Y` 买、`N` 不买；锁定时 `C` 继续、`R` 加注、`F` 弃牌；`Enter` 确认底注或开始下一局。

“显示期望提示”打开时，每个决定都会显示按当前公开信息算出的期望，方便课堂讲解。
电脑玩家的打法：继续、加注、弃牌和要牌都按最佳期望；边注按期望是亏的，电脑玩家当作娱乐型客人，约三成机会购买。

## 文件说明

```
game_code/
├── index.html            页面结构（Vue 3 模板）
├── css/style.css         视觉样式与动画
├── css/fonts.css         内嵌字体 Cinzel（数字与字母）
├── js/engine.js          规则引擎：两副牌、固定牌位、补牌、撞牌判定、结算、策略计算
├── js/app.js             游戏流程与界面逻辑
├── js/sound.js           音效（浏览器即时合成，无音频文件）
├── lib/                  Vue 3 与 canvas-confetti，已放在本地，无需联网
├── tools/simulate.js     V3 赔率模拟器（可选，需要 Node.js）
├── 启动游戏_Mac.command
└── 启动游戏_Windows.bat
```

规则参数集中在 `js/engine.js` 开头（`TARGETS` 和几个常量），每个函数都注明了对应规则的哪一节。

## 赔率模拟器（可选）

装了 Node.js 的同学可以在 `game_code` 文件夹里运行：

```
node tools/simulate.js 200000
```

输出两个目标在最佳打法下的主游戏赌场优势、弃牌率、加注率、各类获胜比例，以及边注的赌场优势。
规则文件第十六节的数字（目标 13 约 3.0%，目标 22 约 3.4%）就是这样算出来的，每次运行会有少许随机波动。
